• The structure preview window allows interactive visualisation of the predicted structure.
  • Structures are coloured by pLDDT to represent the residue-level confidence.
  • Different structures can be previewed by selecting the corresponding row in the results summary table.
  • The preview window can be resized to increase/decrease the viewable area.

What am I looking at?

The 3D viewer shows the predicted arrangement of the predicted structure in three-dimensional space. Individual residues are coloured by predicted Local Distance Difference Test (pLDDT) score. The score ranges from 0 to 100 and reflects the confidence in the local geometry of each residue. Confidence levels often fluctuate across a single protein chain. A detailed module for understanding pLDDT is available in the EBI AlphaFold2 guide (opens in a new tab).

How to interpret pLDDT scores
pLDDT Interpretation
The local structure is predicted with very high confidence.
The local structure is generally reliable.
Treat the predicted region with caution.

Unreliable prediction often caused by:

  1. Naturally unstructured or flexible "disordered" regions
  2. Insufficient information (e.g. MSA depth) to predict structure with confidence.
  • The total number of predictions is described in the table header (11 here).
  • Query ID is the identifier for each prediction derived from the FASTA header of the input Protein Sequences.
  • pTM represents a measure of overall confidence in the global arrangement of the predicted structure. It is a score between 0 and 1 where higher is better.
  • pLDDT represents the confidence in local structure geometry (averaged over the entire prediction). It is a score between 0 and 100 where higher is better.

See example data for the single prediction workflow for a detailed description of structure prediction confidence scores.

Interpreting Your Results

  1. Scenario 1: 🟢 High pTM & 🟢 High pLDDT

    In this scenario, the model has high confidence in both the overall arrangement and local geometry. This prediction is likely high quality.

  2. Scenario 2: 🔴 Low pTM & 🟢 High pLDDT

    In this scenario, the model is highly confident in the local structural geometry but has some uncertainty about global arrangement. This may occur if 2 confidently predicted domains are separated by a flexible linker.
