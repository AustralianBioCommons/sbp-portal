This workflow enables the structure prediction of many molecular systems in a single submission by batching workloads to enable efficient prediction. The interface is powered by the sbp-wisps (opens in a new tab) repository, a bioinformatics best-practice Nextflow pipeline pre-configured and optimised for the Structural Biology Platform and forked from Australian-Structural-Biology-Computing/wisps (opens in a new tab).

Pipeline Steps

The pipeline contains two main computational stages:

Multiple Sequence Alignment (MSA) generation

For each input sequence, the workflow searches UniRef30 and a combined environmental (metagenomics) sequence database using MMseqs2-based colabfold_search (; ). Homologs identified from UniRef30 are paired based on taxonomy labels to support multimer predictions. Independent searches are processed as a large batch so that startup and database-loading costs are not duplicated and the “per structure” SBP credits are reduced compared to running multiple single predictions.

In the SBP deployment, MMSeqs2-based colabfold_search process is conducted locally without calling out to an external public server.

Structure prediction

MSA information is used as input for neural network -based prediction of molecular structures and associated confidence scores. For each tool, SBP retains the top-ranked structure based on predicted confidence. Independent predictions are processed in batches so that startup costs are not duplicated and the “per structure” SBP credits are reduced compared to running multiple single predictions.

Tools

The following structure prediction tools are available to be selected for each run:

  • ColabFold: uses the AlphaFold2 () neural network architecture to convert evolutionary information from an MSA into a three-dimensional protein structure and associated confidence scores. One prediction is generated with each of the five independently trained AlphaFold2 models, and the highest-confidence structure is retained.
  • Boltz: uses the open-source Boltz-2 () model, which has a diffusion-based, AlphaFold3-like architecture. The model iteratively refines initially noisy atomic coordinates to generate a complete three-dimensional structure and associated confidence scores.

Credits Calculation

For the bulk prediction workflow, the SBP credit cost depends on the selected Tool and the number of FASTA entries in the input Protein Sequences. Required credits are displayed during the input configuration and review stage. Below is the formula for calculating total credits for a workflow run.

Boltz example

Number of entries/sequences: 15

Tool multiplier: 1

Total credits needed/utilised: 15 x 1 = 15 credits

ColabFold example

Number of entries/sequences: 15

Tool multiplier: 3

Total credits needed/utilised: 15 x 3 = 45 credits

Since bulk prediction requires at least 10 sequences/entries, at least 10 credits are required to run a workflow employing Boltz, and 30 credits are required and used to run a workflow employing ColabFold. Single Structure Prediction workflow is recommended for predictions of fewer than 10 FASTA entries
