Predicting 3D protein structures using modern AI tools, e.g., AlphaFold2, ColabFold, and Boltz, often requires complex environments, GPU configurations, and command-line execution. Our goal is to make these powerful tools more accessible by providing a user-friendly interface to structural biologists who can easily run, compare, and visualise 3D predictions using these tools through a simple, intuitive dashboard.

Under the hood, this interface is powered by the sbp-proteinfold (opens in a new tab) repository, a bioinformatics best-practice Nextflow pipeline optimised for the Structural Biology Platform and forked from the widely adopted nf-core/proteinfold (opens in a new tab).

This workflow screens all pairwise interactions between the provided query sequences and target sequences. Each query–target pair is evaluated using the selected structure prediction tool (Boltz or ColabFold) to predict structural geometry. Between 10 and 1000 query–target pairs are required per run; for fewer than 10 interactions, use the Single Prediction workflow instead.

Tools

The following structure prediction tools are available to be selected for each run:

  • Boltz is an open-source, multimodal AI model developed by researchers at MIT and Recursion that predicts the 3D structures of complex biomolecular assemblies involving proteins, DNA, RNA, and small molecules (Boltz on GitHub (opens in a new tab)). Its breakthrough feature is the ability to simultaneously calculate highly accurate protein-ligand binding affinities ~1,000 times faster than traditional physics-based free-energy perturbation (FEP) simulations, significantly accelerating early-stage drug discovery (Boltz on GitHub (opens in a new tab); Cancer Grand Challenges (opens in a new tab)).
  • ColabFold is an open-source platform that drastically accelerates AI-driven protein structure prediction models, such as AlphaFold2, by replacing their standard homology search with the ultra-fast MMseqs2 algorithm. Its breakthrough feature is the ability to generate sequence alignments 40–60 times faster than traditional methods, democratising access to complex protein and multimer predictions without requiring massive computational infrastructure (Mirdita et al., 2022 (opens in a new tab)).

Credits Calculation

Credits are required to execute workflows and will be consumed upon workflow submission. The credit balance refreshes to 1000 on the 1st of each month.

For the interaction screening workflow, the number of credits required to run a workflow depends on the tool and the number of input sequences/entries.

Total credits required and utilised in a workflow are calculated and displayed during the input configuration and review stages. Below is the formula for calculating total credits for a workflow run.

Boltz example

Number of query sequences: 5

Number of target sequences: 6

Tool multiplier: 1

Total credits needed/utilised: Tool multiplier × (query sequences × target sequences) = 1 × (5 × 6) = 30 credits

ColabFold example

Number of query sequences: 5

Number of target sequences: 6

Tool multiplier: 5

Total credits needed/utilised: Tool multiplier × (query sequences × target sequences) = 5 × (5 × 6) = 150 credits

Since interaction screening requires at least 10 query–target pairs per run (the Single Structure Prediction workflow is recommended for fewer than 10 query–target pairs), at least 10 credits are used to run a workflow employing Boltz, and at least 50 credits are required and used to run a workflow employing ColabFold.

Input Configuration and Tool Settings

Below are the input parameters available to users to customise their workflow, the accepted format of each parameter, and the behaviour and limits, if any, of each parameter.

Input parameters, accepted formats, and behaviour and limits
Input Accepted formats Behaviour and limits
Job Name A string containing letters, numbers, hyphens, and underscores

Mandatory/Required identifier for the job/workflow run

Must not start with a number
Query Sequences

One or more protein sequences in FASTA format

Each entry must have a unique header line starting with >, followed by the sequence on the next line.

Each protein sequence must contain only the 20 canonical amino acids (ARNDCQEGHILKMFPSTWYV).

Multimeric sequences are accepted with a header followed by two or more sequences separated by colons, e.g., SEQUENCEA:SEQUENCEB:SEQUENCEC.

Please note that for compute cost calculation, multimeric sequences will be counted as a single sequence.

Mandatory input

Minimum 10 query–target pairs

Maximum 1000 query–target pairs

Each entry/sequence must not contain more than 1000 amino acid residues.

Multimeric sequences are accepted with a header followed by two or more sequences separated by colons, e.g., SEQUENCEA:SEQUENCEB:SEQUENCEC.
