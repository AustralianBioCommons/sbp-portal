This workflow enables the structure prediction of an individual molecular system comprising one or more molecular entities. The interface is powered by the sbp-proteinfold (opens in a new tab) repository, a bioinformatics best-practice Nextflow pipeline pre-configured and optimised for the Structural Biology Platform and forked from nf-core/proteinfold ().

Pipeline Steps

The pipeline contains two main computational stages:

Multiple Sequence Alignment (MSA) generation

For protein inputs, the workflow searches large reference sequence databases for homologs and constructs a multiple sequence alignment (MSA). AlphaFold2 () uses its standard search workflow, to generate input features including JackHMMER () to search small_bfd (when not using Full DBs), MGnify (), and uniref90 (plus PDB for structural templates and uniprot for a paired MSA when predicting multimers). HHsearch () is used to search PDB70 for structural templates (and HHblits () to search UniRef30 + BFD when using Full DBs).

In the SBP deployment, all reference databases are maintained and regularly updated as part of the “AI structural biology reference collection” ().

ColabFold () and Boltz () use an MMseqs2-based () colabfold_search pipeline to generate MSAs more rapidly. MMSeqs2 is used to search UniRef30 and a combined environmental (metagenomics) sequence database. Homologs identified from UniRef30 are paired based on taxonomy labels to support multimer predictions.

In the SBP deployment, MMSeqs2-based colabfold_search process is conducted locally without calling out to an external public server.

Structure prediction

The generated MSAs (and structural templates for AlphaFold2) are used as input for neural network -based prediction of molecular structures and associated confidence scores. For each tool, SBP displays the top-ranked structure based on predicted confidence.

Tools

The following structure prediction tools are available to be selected for each run:

  • AlphaFold2: uses the standard AlphaFold2 search pipeline to generate an MSA and a list of structural templates. This data is provided as input to an ensemble of 5 deep-learning models (repeated 5 times each for multimer predictions) to predict protein structures.
  • ColabFold: uses an accelerated MMseqs2-based homology search (colabfold_search) to generate MSAs to use as neural network inputs. A single replicate of each of the 5 AlphaFold2 models is used for structure prediction.
  • Boltz: uses MMSeqs2-based colabfold_search to generate input MSAs in combination with a diffusion-based, AlphaFold3-like architecture for structure prediction. As a result, Boltz is able to co-fold complexes containing proteins, DNA, RNA and small molecules.

In the SBP deployment, the Boltz-2 model is used within the LMI4Boltz () framework to increase the maximum prediction size compared to the Boltz-2 implementation.

Credits Calculation

Credits are required to execute workflows and are consumed when a workflow is submitted. The credit balance refreshes to 1000 on the first day of each month. A single prediction run costs 50 credits, irrespective of the selected tool. Tool-specific input-size limits are enforced during configuration.

Input Configuration and Tool Settings

Below are the input parameters available to users to customise their workflow, the accepted format of each parameter, and the behaviour and limits, if any, of each parameter.

AlphaFold2 and ColabFold only support protein entities, while Boltz also supports RNA, DNA and small-molecule ligands.
