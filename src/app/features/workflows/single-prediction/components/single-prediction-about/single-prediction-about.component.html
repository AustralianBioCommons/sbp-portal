Predicting 3D protein structures using modern AI tools, e.g., AlphaFold2, ColabFold, and Boltz, often requires complex environments, GPU configurations, and command-line execution. Our goal is to make these powerful tools more accessible by providing a user-friendly interface to structural biologists who can easily run, compare, and visualise 3D predictions using these tools through a simple, intuitive dashboard.

Under the hood, this interface is powered by the sbp-proteinfold (opens in a new tab) repository, a bioinformatics best-practice Nextflow pipeline optimised for the Structural Biology Platform and forked from the widely adopted nf-core/proteinfold (opens in a new tab).

Tools

The following structure prediction tools are available to be selected for each run:

  • AlphaFold2 is an advanced AI system developed by Google DeepMind that predicts the 3D structures of proteins from their one-dimensional amino acid sequences with unprecedented, atomic-level accuracy (). Its breakthrough feature is the use of a novel attention-based neural network architecture that incorporates evolutionary and geometric constraints, effectively solving the 50-year-old "protein folding problem" by matching the accuracy of experimental techniques like X-ray crystallography (; ).
  • Boltz is an open-source, multimodal AI model developed by researchers at MIT and Recursion that predicts the 3D structures of complex biomolecular assemblies involving proteins, DNA, RNA, and small molecules (Boltz on GitHub (opens in a new tab)). Its breakthrough feature is the ability to simultaneously calculate highly accurate protein-ligand binding affinities ~1,000 times faster than traditional physics-based free-energy perturbation (FEP) simulations, significantly accelerating early-stage drug discovery (Boltz on GitHub (opens in a new tab); Cancer Grand Challenges (opens in a new tab)).
  • ColabFold is an open-source platform that drastically accelerates AI-driven protein structure prediction models, such as AlphaFold2, by replacing their standard homology search with the ultra-fast MMseqs2 algorithm. Its breakthrough feature is the ability to generate sequence alignments 40–60 times faster than traditional methods, democratising access to complex protein and multimer predictions without requiring massive computational infrastructure ().
Which tool to use
Tool Use it when you want to…
ColabFold Quickly predict a protein structure or protein complex using an AlphaFold-based workflow.
AlphaFold2 Predict the 3D structure of a protein using the established AlphaFold2 approach.
Boltz Predict more complex biomolecular systems involving proteins, DNA, RNA, or small molecules.

Credits Calculation

Credits are required to execute workflows and will be consumed upon workflow submission. The credit balance refreshes to 1000 on the 1st of each month. The tools for single structure prediction utilise 50 credits for each run, with different size limits enforced as indicated in the table below.

Boolean

Default: False

Boltz specific

Steering potentials are used by Boltz to improve the physical validity of output predictions (e.g., steric clashes, incorrect chirality) (nf-core/proteinfold docs (opens in a new tab)).

Using potentials increases execution time and memory requirements and decreases the maximum size limit.
