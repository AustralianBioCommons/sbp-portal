Under the hood, this interface is powered by the sbp-proteindj (opens in a new tab) repository, a bioinformatics best-practice Nextflow pipeline pre-configured and optimised for the Structural Biology Platform and forked from the widely adopted PapenfussLab/ProteinDJ (opens in a new tab) . (Silke et al., 2026 (opens in a new tab))

PyRosetta has been removed as a dependency (opens in a new tab) from all stages of the ProteinDJ workflow. As a result, the platform does not impose licensing restrictions on outputs generated by users.

Pipeline Steps

The de novo design pipeline contains four modular steps:

Backbone generation

RFdiffusion or BindCraft generates candidate protein backbones designed to interact with the uploaded Target Structure at a site defined by user-supplied Target Hotspot Residues. In the SBP deployment, the number of generated backbones is determined by the user-supplied Number of Designs, with lengths sampled uniformly in the Binder Length Range.

Sequence design

For each designed backbone, ProteinMPNN assigns amino-acid sequences to the candidate backbones, aiming to produce sequences compatible with the target interface. After threading a designed sequence onto the corresponding backbone, interface clashes are resolved by OpenMM relaxation before an additional sequence design iteration with ProteinMPNN. In the SBP deployment, 8 sequences are designed for each generated backbone, such as 8 × 100 sequences when selecting 100 designs.

Structure prediction

AlphaFold2 Initial Guess is used to predict the structure of each designed target-binder complex. Designed structures are provided to AlphaFold2 as an initial guess to aid prediction without relying on an input multiple sequence alignment.

Analysis

Predicted structures and associated confidence scores are used to assess whether the binder is likely to adopt the intended structure and interaction. Designs are filtered and ranked using these scores, and users receive ranked structures together with downloadable CSV files containing the results. SBP only reports designs with PAE interaction < 10 Å, pLDDT > 80, and binder RMSD < 1 Å. Results are ranked by the PAE interaction.

Filter pass rate can be highly target and hotspot dependent. Some runs will generate no outputs that meet the filtering criteria and will not return any output files. To overcome this limitation, try different Target Hotspot Residues combinations or increase the Number of Designs.

Tools

The following protein design tools are available to be selected for each run:

  • RFdiffusion is a generative AI model based on the RoseTTAFold structure-prediction architecture. Rather than predicting the structure of an existing protein sequence, it generates new protein backbones by iteratively refining random input noise. When provided with a target structure and selected hotspot residues, RFdiffusion can generate candidate binder backbones designed to interact with the target.
  • BindCraft is an AI-based protein-design method that uses structure hallucination to generate candidate proteins designed to bind a target. During hallucination, an AlphaFold2-based model iteratively adjusts a randomly initialised binder sequence to improve its predicted interaction with a specified target region. BindCraft cycles through multiple AlphaFold2 models to avoid overfitting. In a standard BindCraft execution, hallucinated designs are subsequently redesigned, structure-predicted, and filtered to identify the most promising candidates.

In the SBP deployment, BindCraft is used only to generate candidate binder backbones. Downstream processing is implemented in the unified ProteinDJ workflow but closely resembles the steps integrated in standard BindCraft processing.

Credits Calculation

Credits are required to execute workflows and will be consumed upon workflow submission. The credit balance refreshes to 1000 on the 1st of each month.

For the de novo design workflow, the number of credits required to run a workflow depends on the selected tool and the number of designs.

Total credits required and utilised in a workflow are calculated and displayed during the input configuration and review stages. Below is the formula for calculating total credits for a workflow run.

RFdiffusion example

Number of designs: 100

Tool multiplier: 4

Total credits needed/utilised: Tool multiplier × (Query sequences × Target sequences) = 4 × 100 = 400 credits

BindCraft example

Number of designs: 100

Tool multiplier: 10

Total credits needed/utilised: Tool multiplier × (Query sequences × Target sequences) = 10 × 100 = 1000 credits

Input Configuration and Tool Settings

Below are the input parameters available to users to customise their workflow, the accepted format of each parameter, and the behaviour and limits, if any, of each parameter.

Input parameters, descriptions, and behaviour and limits
Input Description Behaviour and Limits
Target Structure Protein structure in PDB format.

Minimum size: 50 amino acids

Maximum size: 300 amino acids
Job Name Identifier for the job/workflow run.

Alphanumeric input including hyphens and underscores.

Must not start with a number.
Target Hotspot Residues

A string containing comma separated residues defined by chain ID and residue index.

E.g. “A56,A58”

Minimum: 1 hotspot.

Maximum: 8 hotspots.
Binder Length Range A minimum and maximum value to bound the length of generated binders. Binders are sampled uniformly in the specified length range.

Length range between 65 and 150 residues.
Number of Designs The number of folds generated by RFdiffusion/BindCraft.

Minimum of 1 generated fold.
